# Widget catalog

A widget is the unit this fixture bundle sells. Widgets ship in blue and in green,
and the catalog records the price, the weight, and the colour of every one of them
so that a search has some prose to pull a snippet out of rather than a single line.

No concept in this bundle carries the word the reserved files are stuffed with, so a
search that finds it has read an index.md or a log.md.
